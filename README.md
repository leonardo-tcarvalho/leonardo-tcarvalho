## 🧠 About Me

I'm a software engineer with 3 years building web applications, REST APIs, and internal systems — the kind of work that actually gets used by real people every day.

I work across the full stack: PHP, TypeScript, and React on the frontend and backend, Python scripts for automation, SQL Server and MySQL for data, and AWS for infrastructure. More recently I've been integrating OpenAI's API and n8n to automate repetitive workflows — cutting manual steps out of processes that didn't need a human in the loop.

I'm comfortable with Docker, CI/CD pipelines via GitHub Actions, and have freelance experience delivering WordPress sites with a focus on performance and SEO.

I'm looking for mid-level full-stack, backend, or cloud-adjacent roles in Portugal, Spain, the Netherlands, Germany, or remote-EU. Open to hybrid and relocation. If you're building something interesting, let's talk.
